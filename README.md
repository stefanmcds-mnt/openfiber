# OpenFiber

OpenFiber è una libreria l'interfacciamento dinamico e asincrono tra OLO e B2B Gateway di Open Fiber.

### Scopo
Abbiamo avviato questo progetto da condividere con la comunità al fine di agevolare gli OLO (piccoli e medi) a migrare verso soluzione API B2B di OpenFiber, che intendono o meno abbandonare progressivamente il PortaleOperatori.

### Contributi
Siamo disponibili e auspichiamo che lo sia che per altri sviluppatori in particolare gli OLO contribuiscano a questo progetto.

### Articolazione
Il progetto è suddiviso per tipo linguaggio:
OpenFiber
    ├── PHP
    ├── PYTHON
    ├── JAVA

### Implmentazioni
La libreria realizzata per il momento è in cartella PHP, stiamo ampliando sviluppando la libreria in PYTHON.
